# Versioning Privacy / Terms (and cookie notice)

Policies are documents clients and auditors read. Treat them like releases.

## On every policy page

| Element | Why |
|---|---|
| **Effective date** (and “last updated”) | Proof of which text applied when |
| **Version id** optional (`2026-10-22`, `v3`) | Support + evidence pack |
| Short **what changed** (for material updates) | Trust; GDPR transparency mindset |

## When to bump

| Change | Action |
|---|---|
| New processor / analytics / AI training claim | New effective date + notify if required (compliance) |
| Typo only | Patch date or silent fix — prefer noting “editorial” |
| Legal basis / rights / retention rewrite | Material → counsel if unsure; always new date |
