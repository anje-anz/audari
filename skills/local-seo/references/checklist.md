# Local SEO checklist

| ID | Check | Done-when |
|---|---|---|
| L1 | Title unique | `Service in Area | Brand` (or clear variant) |
| L2 | Meta description | Honest; includes area + CTA hint |
| L3 | H1 | One; matches intent of title |
| L4 | NAP footer | Same spelling as intake + GBP |
| L5 | `tel:` / maps link | Work on mobile |
| L6 | Service area block | Neighbourhoods **actually** served |
| L7 | Internal links | Home ↔ Services ↔ Contact |
| L8 | JSON-LD LocalBusiness | See schema.md — matches visible NAP |
| L9 | GBP | Profile URL linked; site URL = canonical after deploy |
| L10 | Consistency | Site ↔ GBP ↔ intake (no conflicting hours) |

Chrome (robots, sitemap, OG) → `site-checklist`.
