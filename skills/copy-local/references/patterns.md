# Section patterns

## Hero

- **Line 1:** service + area (what + where)  
- **Line 2:** one differentiator **from intake** or omit  
- **CTA button:** verb matching channel (“Call now”, “WhatsApp”, “Book”)  

Bad: “Welcome to our innovative holistic solutions.”  
Good: “Emergency plumbing in Riverside — call before 6pm.”

## Services

- Name the job in customer words  
- One line “when you need this”  
- Optional “from €X” only if confirmed  

## About

- 2–4 sentences: who, where, how long / credential **if real**  
- Skip biography novels  

## FAQ

- 3–5 real objections: area covered, emergency, pricing style, parking  
- Answers short; link to call if nuance  

## Contact

- Repeat NAP  
- Restate hours  
- Same CTA as hero  

## EN vs IT

- Match locale; don’t mix casually  
- IT: informal “tu” only if brand is casual; default clear professional  
- Keep service nouns locals actually search
