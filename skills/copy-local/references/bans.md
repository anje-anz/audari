# Ban / rewrite list

| Pattern | Do instead |
|---|---|
| “Welcome to our website” | Service + area |
| “We are passionate about excellence” | Concrete differentiator or delete |
| “Your trusted partner for all your needs” | Name 1–2 services |
| “#1 / best / leading” without proof | Remove |
| Star ratings you didn’t earn | Remove |
| “AI-powered” for a barber site | Remove unless true and relevant |
| Lorem / “Coming soon” on public | Intake or hide section |
| Guaranteed outcomes (medical, legal, wealth) | Stop — compliance |
| Walls of adjectives | One noun-heavy sentence |

After oil-tone: re-check this list — natural prose still cannot invent claims.
