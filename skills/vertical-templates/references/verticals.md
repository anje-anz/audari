# Vertical spines (starter set)

Each spine = default **IA + section jobs**. Clone a row into a new slug when needed.
Copy is structural — replace with intake.

Shared chrome (all): sticky header CTA, footer NAP, Privacy/Terms links,
mobile sticky call/WhatsApp if that’s the CTA.

## `trades` (plumber, electrician, locksmith, HVAC)

| Section | Job |
|---|---|
| Hero | Service + area + call CTA |
| Services | 4–8 jobs with short “when you need us” |
| Why us / trust | Insurance, response time, years — **only real claims** |
| Service area | Neighbourhoods list |
| Reviews strip | Embed or quotes with permission |
| FAQ | Emergency, pricing style, coverage |
| Contact | Form and/or tel: |
