# Client intake (minimum)

**Prefer skill `client-intake`** for full field status + output block.
This file remains a short cheat sheet for vertical-templates.

Collect before personalizing. One message or form is enough.

## Must have

| Field | Why |
|---|---|
| Legal / trading name | Title, footer, schema |
| Vertical / services list | Services section (3–8 items) |
| Area served (city/neighbourhood) | Local SEO + H1 |
| Phone + email (public) | Click-to-call / contact |
| Address or “mobile service” | NAP / maps |
| Opening hours | Hours block or “by appointment” |
| 3–8 photos (or stock OK flagged) | Hero + gallery |
| Primary CTA | Call / WhatsApp / book / form |
| Logo (or text wordmark) | Header |
| Language(s) | Locale |

## Nice to have

| Field | Why |
|---|---|
| Google Business Profile URL | Link + consistency check |
| 2–3 differentiators | About (not generic “quality service”) |
| Price orientation | “from €X” — only if they want it public |
| Competitors they like | Fit template, don’t clone illegally |
| Existing domain / socials | Links footer |

## Rules for the agent

- Missing must-haves → ask **once**, grouped; don’t block on nice-to-haves.
- Invented facts → prefix `(placeholder)` in the build and list them at handoff.
- Never scrape private data; only use what the client or public pages provide.
