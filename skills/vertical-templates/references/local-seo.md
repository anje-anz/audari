# Local SEO surface (template defaults)

**Prefer skill `local-seo`** for the full checklist + schema rules.
This file is the short surface still used inside vertical packing.

Enough for the base pack. Not a full SEO agency retainer.

## On-page (every vertical)

| Item | Done-when |
|---|---|
| Unique title/description | Include **service + area** (e.g. “Emergency plumber in Riverside”) |
| One H1 | Same intent; don’t keyword-stuff |
| NAP in footer | Name, Address (or mobile service), Phone — consistent spelling |
| `LocalBusiness` (or subtype) JSON-LD | Matches visible NAP; no fake ratings |
| Click-to-call / maps link | Real `tel:` and Google Maps URL when address exists |
| Internal links | Home ↔ Services ↔ Contact |

Handoff full chrome (robots, sitemap, OG, 404) → `site-checklist`.

## Google Business Profile (client-owned)

| Item | Who |
|---|---|
| Claim / verify GBP | Client (you can guide) |
| Categories + services match site | Client + you check |
| Site URL on GBP = this site | You |
| Photos not stolen | Client |

Template sites should **link to GBP**, not replace it.

## Don’t

- Fake review stars in JSON-LD  
- Stuff every suburb in hidden text  
- Promise “#1 on Google” in sales copy for this pack
