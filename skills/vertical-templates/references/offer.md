# Offer pack (defaults)

Adjust if the user overrides. Keep **base thin**; sell depth as add-ons.
**Never invent list prices** — use the user’s rate card for amounts.

## Base — one-time

| Included | Not included |
|---|---|
| 1 vertical template, 1 locale (start) | Custom illustration / photo shoot |
| Swap: name, colors (light), services, contacts, hours | Unique art-direction from scratch |
| Home + Services + About/Area + Contact | Full blog CMS / member area |
| Soft-launch chrome via `site-checklist` | Motion/WebGL showcases |
| Privacy + Terms stubs wired (content → compliance pass) | Ongoing SEO retainer beyond care |
| Mobile-responsive layout | Multi-location franchise systems |

## Care — monthly

**Authoritative inclusions / exclusions / runbook:** skill `deploy-care`
(`care-plan.md`, `not-included.md`). Do not leave care vague in the quote.

Typical: hosting + TLS + break-glass + tiny text-tweak cap — **not** SEO retainer,
ads, or weekly content.

| Add-on | Typical scope | Price |
|---|---|---|
| Contact form + email notify | Spam control + thank-you | rate card |
| WhatsApp / click-to-call sticky | Mobile CTA | rate card |
| Booking | Cal.com / Calendly embed or deep link | rate card |
| Gallery / before-after | Optimized images | rate card |
| Google Maps embed | One location | rate card |
| Extra language | Second locale strings | rate card |
| Blog / updates | 3 starter posts + CMS light | rate card |

Put real amounts in your studio rate card; the skill only forces **naming** add-ons so scope doesn’t melt into base.
