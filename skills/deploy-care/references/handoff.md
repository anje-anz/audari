# Client handoff pack

Send after first production deploy (email or shared doc).

## Must include

| Item | Example |
|---|---|
| Production URL | `https://www.example.ie` |
| Staging / preview (if any) | `https://….vercel.app` — noindex |
| What care includes | Link or paste from care-plan.md for **this** quote |
| How to request a tweak | Email/WhatsApp; remind monthly cap |
| Content they own | Hours, prices, photos, claims |
| Domain owner | Registrar account = client or studio (state which) |
| Admin access | Vercel viewer? CMS? Usually studio-operated under care |

## Must not include

- Host secrets, service-role keys, full `.env`  
- Other clients’ URLs or credentials  
- Promises not in the signed quote  

## Optional

| Item | When |
|---|---|
| How to edit GBP | Always useful |
| How booking add-on works | If Cal.com linked |
| Invoice / care start date | Billing |

## Agent checklist before sending

- [ ] HTTPS works on canonical host  
- [ ] Privacy/Terms linked in footer  
- [ ] Contact CTA works (tel or form test)  
- [ ] Care inclusions match the quote language
